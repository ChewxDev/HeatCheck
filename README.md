# HEATCHECK

HEATCHECK is a private, consent-first adult desire discovery web app created by Chwx.

## Features

- 84 curated prompts across multiple desire categories
- Quick, full-spectrum, and after-dark decks
- Interest, context, role, and hard-limit responses
- Personalized Freak List archetypes
- Downloadable PNG and supported H.264/MP4 results
- Browser-local storage and panic clearing
- Responsive mobile design with reduced-motion support

## Run locally

```sh
python3 -m http.server 4173 --directory dist
```

Then open `http://127.0.0.1:4173`.

## Privacy

Responses remain in the visitor's browser. Exported lists omit answers marked private.
